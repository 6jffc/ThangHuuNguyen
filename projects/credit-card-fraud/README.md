# Predicting Credit Card Fraud — S6E11

This project page is part of the [ThangHuuNguyen portfolio](https://6jffc.github.io/ThangHuuNguyen/).

## Research scope
- Binary fraud classification and probability ranking
- Exploratory data analysis and train/test auditing
- Confusion matrix, ROC curve and ROC-AUC
- Leakage-safe validation and baseline modeling
- Reproducible experiment tracking

## Important research note
All numeric transactions shown in the interactive threshold example are synthetic teaching data. The repository page deliberately contains no fabricated competition score. Record ROC-AUC only after running the notebook against the actual competition files.

## Dataset
Download the competition data from Kaggle and keep the original files outside version control unless the competition license explicitly permits redistribution. Update notebook paths and verify the target and feature names against the downloaded schema before running code.
